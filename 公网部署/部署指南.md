# 公网中继部署指南（一次配置，之后玩家只需输入房间号）

目标：把中继服务器部署到公网，拿到一个固定地址（如 `https://xxx.onrender.com`），
然后我会把这个地址**内置进游戏**——此后任何人打开页面点「联机对战」→ 输入房间码就能玩，无需再管服务器。

推荐平台：**Render**（免费、免信用卡、代码几乎不用改）。
> 备选：Koyeb（同样免费，步骤类似，用 GitHub 或 `koyeb` CLI 部署）。

---

## 第一步：注册 Render（约 2 分钟）
1. 打开 https://render.com ，点 **Get Started**，
2. 选 **Sign up with GitHub**（最快）或邮箱注册。

## 第二步：把项目传到 GitHub（不用命令行，网页拖拽即可）
1. 登录 https://github.com ，右上角 **+** → **New repository**，
   - Repository name 填 `netbattle-relay`，可见性选 **Public**，点 **Create repository**。
2. 在仓库页点 **Add file → Upload files**，
3. 把本机 **`C:\进化史\公网部署\`** 里的**全部内容**拖进去（`server.js`、`package.json`、`render.yaml`、`deploy` 文件夹，共约 35 个文件），
4. 点 **Commit changes**。

## 第三步：用 Blueprint 一键部署
1. 打开 https://dashboard.render.com ，点 **New +** → **Blueprint**，
2. 选择刚创建的 `netbattle-relay` 仓库 → **Connect**，
3. Render 会读到 `render.yaml` 并列出服务 `netbattle-relay` → 点 **Apply**，
4. 等 1~3 分钟，状态变成 **Live**。

## 第四步：把地址给我
在服务详情页顶部拿到地址，类似：
```
https://netbattle-relay-a1b2.onrender.com
```
**把这个地址发给我**，我会：
- 把它内置成游戏默认联机地址（`wss` 开头那个）；
- 重新构建并发布；
- 之后你和朋友都只需：打开页面 → 联机对战 → 创建/输入房间号 → 玩。

> 小技巧：这个 Render 地址本身也能打开游戏（页面 + 中继同源），
> 朋友直接开 `https://xxx.onrender.com` 也是零配置联机。

---

## 注意事项
- **免费档会休眠**：约 15 分钟无人访问后服务器休眠，之后第一个加入要等 **30~60 秒**唤醒
  （游戏里已加"正在唤醒，请稍候"提示）。想避免休眠：注册一个免费
  [UptimeRobot](https://uptimerobot.com) 监控，每 10 分钟访问一次
  `https://你的地址/healthz` 即可（这个健康检查接口我已经加好了）。
- 以后更新中继代码：把新的 `server.js` 传到 GitHub，Render 会自动重新部署。
- 部署出问题就看 Render 的 **Logs** 标签页，90% 是漏传文件（`server.js`/`package.json` 必须在仓库根目录）。
